# 足球密码网站运维说明

## 仓库定位

本仓库负责网站执行；上游总部 `msjddnjsjdbd-stack/taobao-visual-system` 负责商品事实、品牌规则、视觉铁律、商品任务卡与 QC。

## 新商品上架

1. 在总部确认商品名称、品牌、价格、图片、基础描述和购买链接。
2. 将确认后的展示图放入 `images/`。
3. 在 `data/products.json` 新增一条商品记录。
4. 不需要复制 HTML 商品卡；`index.html` 会自动读取 JSON 并渲染。
5. 本地或预览环境检查：图片路径、商品数量、价格、中文、按钮、移动端布局。
6. 通过分支 / PR 合并。

## 商品数据字段

- `id`：稳定唯一标识，不随文案调整频繁改变
- `brand`：真实品牌
- `name`：网站展示名
- `category`：分类
- `price`：已确认价格，数字
- `currency`：当前使用 `CNY`
- `image`：仓库内相对路径
- `alt`：图片替代文本
- `tag`：短标签
- `description`：只写已确认事实
- `purchaseUrl`：真实购买链接；未知时留空字符串

## 禁止事项

- 不根据图片主观推断功能卖点。
- 不擅自使用“联名、官方合作、授权”等关系型表述。
- 不把未确认促销、库存、售后写进页面。
- 不用临时外链替代仓库内正式商品图，除非用户明确要求。
- 不直接在 `index.html` 再硬编码一套商品价格和描述。
