## 标准上架流程

1. 先从总部确认商品事实、图片、价格与文案。
2. 将网站用图片放入 `images/`。
3. 更新 `data/products.json`。
4. 检查 `index.html` 是否正常渲染。
5. 检查手机端排版、价格、图片、按钮和中文文案。
6. 通过分支 / PR 合并到 `main`。
